## 备注:About 页崩溃 + mdx frontmatter YAML 陷阱

- 用户点 About 报 `Cannot read properties of undefined (reading 'body')`。根因:`data/authors/default.mdx` 的 frontmatter 占位值含 `: `(冒号+空格,如 `【TODO: 你的昵称】`、`【TODO: https://github.com/你的用户名】`),YAML 把未加引号的 `TODO: ` 当作键值对,整段 frontmatter 解析错乱,contentlayer 直接丢弃该作者文档 → allAuthors 无 default。
- 修复:占位值加单引号包裹;`name` 填 `wangchaoqi`(与 siteMetadata.title 一致)。js-yaml 实测可正常解析。
- `app/about/page.tsx` 加了诊断性 throw:找不到 author 时抛错并列出 allAuthors 现有 slug,开发期便于定位。
- **约定**:此后所有 .mdx frontmatter 的 TODO/占位值**必须用引号包裹**,避免 `: ` 破坏 YAML。siteMetadata.js 是 JS 对象,不受此限。
